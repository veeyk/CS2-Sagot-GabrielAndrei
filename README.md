# What is this? (Description)
Essentially, this is a fork of the original electricity calculator. Here are the differences
 # Version 1
Input: Accepts a customers name regardless if it's empty. 
Process: Processes' the data, even if it's a negative number, or a previous number that surpasses the current. Which, in turn, messes up the results.
Output: Accurate if done right, however there are major issues to be solved.
Does not include input validation

# Version 2
Input: Accepts a customers name, unless they have nothing in the box. 
Process: Processes only what it can accurately measure. It rejects negative numbers and does not allow the previous value to surpass the current one.
Output: Accurate, more times than version 1. There could be more improvements, still.
Does include input validation
